# Shayan Irshad Portfolio

## Run locally

1. Install Node.js (current LTS recommended).
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL printed by Vite.

## Motion and navigation

- Copper-toned reveal-on-scroll transitions and subtle card hover states.
- Active navbar section updates while scrolling; desktop and mobile links target the same section IDs.
- Canvas background pauses when the tab is hidden, uses fewer particles on mobile, and respects reduced-motion preferences.
- Custom cursor is disabled on touch devices and when reduced motion is enabled.
- Project demo links currently route to Contact until real project URLs are added. Replace the example GitHub profile with the project repository links you own.
